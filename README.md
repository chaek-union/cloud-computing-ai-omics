# AI와 오믹스 연구를 위한 클라우드 컴퓨팅

저자: 안준용

---

이 책은 클라우드 컴퓨팅과 AI를 연구에 처음 도입하려는 학부 고학년과 대학원 초급 연구자를 위한 오믹스 분석 입문서다. 유전체 변이 분석에서 출발해 single-cell, spatial transcriptomics, 이미징 오믹스까지 범위를 넓혀 가며, 대용량 데이터를 저장하고 이동시키는 문제에서부터 생성형 AI를 해석 계층으로 얹는 방법까지 단계적으로 설명한다. 목표는 AWS 서비스 이름을 외우게 하는 것이 아니라, 왜 오믹스 연구가 클라우드를 필요로 하게 되었는지, 언제 데이터를 옮기지 않고 바로 연결하는지, 어떤 AI 도구를 어느 분석 단계에 얹어야 하는지를 이해시키는 데 있다. 책은 EC2, S3, EBS, IAM Role 같은 기본 인프라 개념에서 출발해 gnomAD, SRA, EMR, Hail, AWS HealthOmics, SageMaker, Zarr와 TileDB-SOMA, 시퀀싱 센터 데이터 공유와 전처리, 연구 재현성, 그리고 Claude, Kiro, Bedrock을 활용한 최신 해석 자동화까지 하나의 연구 플랫폼 이야기로 엮어 다룬다. 각 장은 개념 설명, 실제 연구 시나리오, 설계 감각을 기르는 질문을 중심으로 구성한다.
